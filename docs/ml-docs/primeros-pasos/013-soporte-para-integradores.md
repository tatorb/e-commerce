# Soporte para Integradores

Última actualización 14/10/2026

Developer Partner Program

## Soporte para integradores

Abrí consultas y reportá problemas técnicos con el equipo de soporte especializado del Developer Partner Program (DPP).

## SLA de primera respuesta personalizada

Los siguientes tiempos aplican a la atención personalizada del equipo de soporte, cuando es necesaria. Antes, un bot disponible las 24 horas, los 7 días de la semana, brinda soporte inmediato.

| Nivel | SLA de primera respuesta personalizada |
| --- | --- |
| Silver | 2 días hábiles |
| Gold | 1 día hábil |
| Platinum | 3 horas hábiles |

Horarios de atención:

La atención personalizada se brinda de lunes a viernes, de 9:00 a 18:00 h (GMT-3, Argentina).

## Crear un ticket

Completá estas cuatro etapas para registrar tu consulta o problema.

1. **Categoría:**  Elegí el tema de tu consulta.

2. **Aplicación:**  Indicá la aplicación asociada.

3. **Descripción:**  Explicá el caso con el mayor detalle posible.

4. **Envío:**  Confirmá la creación del ticket.

### Seleccionar la categoría y la subcategoría

Indicá el área temática de la consulta o del problema. Podés seleccionar una de las siguientes categorías:

- Vehículos

- Inmuebles

- Productos

Después de seleccionar la categoría, elegí una subcategoría. Antes de continuar, el sistema muestra un enlace a la documentación correspondiente.

### Subcategorías de Productos

| Subcategoría | Descripción |
| --- | --- |
| Órdenes | Problemas o consultas relacionadas con la gestión de órdenes de compra. |
| Publicaciones | Errores al crear, modificar o pausar ítems mediante la API. |
| Pagos | Incidencias con cobros, devoluciones o conciliación. |
| Envíos | Problemas con la logística o la generación de etiquetas. |

### Seleccionar la aplicación

Indicá la aplicación relacionada con la consulta o el problema.

| Campo | Descripción |
| --- | --- |
| ID de aplicación o nombre de la aplicación | Campo con autocompletado. Al ingresar el ID de aplicación o el nombre, el sistema resuelve y completa el otro valor automáticamente, con validación en tiempo real. |

Si iniciás sesión con una cuenta que tiene aplicaciones asociadas, el sistema completa este campo automáticamente. Cuando resuelve la aplicación, muestra su medalla DPP (Silver, Gold o Platinum) para que identifiques el SLA de primera respuesta personalizada aplicable al ticket.

### Describir el problema o la consulta

Seleccioná el tipo de ticket:

- **Consulta:**  solicitás orientación, una aclaración o información sobre el funcionamiento de la API o de una funcionalidad.

- **Problema:**  reportás un error, un comportamiento inesperado o una falla técnica que impacta en tu operación.

### Campos requeridos para ambos tipos de ticket

| Campo | Descripción |
| --- | --- |
| Asunto | Título breve y descriptivo del ticket. |
| Descripción | Detalle de la consulta o el problema, de hasta 5000 caracteres. Incluí el comportamiento esperado, el comportamiento actual y los pasos para reproducir el error. |

### Campos adicionales para tickets de tipo Problema

| Campo | Descripción | Recomendado |
| --- | --- | --- |
| Vendedores o usuarios afectados | Indicá si afecta a un vendedor o usuario específico, a varios o a todos. | No |
| IDs de vendedores o usuarios | Ingresá los IDs separados por coma. Ejemplo: 12345678, 23456789. | No |
| Método | Método HTTP del endpoint: GET, PUT, POST o DELETE. | Sí |
| Recurso | URL del endpoint que genera el error. | Sí |
| Request | Cuerpo o parámetros de la petición enviada. | Sí |
| Respuesta | Response completo de la API, incluidos el código HTTP y el body. | Sí |

Completá los campos técnicos:

El equipo de soporte solicita esta información como primer paso. Un ticket completo acelera la resolución y puede ahorrar hasta 24 horas de espera por el desfase horario con otros equipos.

**Email de notificación:**  las respuestas llegan de forma predeterminada al email de la cuenta. Si necesitás recibirlas en otra casilla, por ejemplo la del equipo o la de la persona responsable de la cuenta, se puede sumar en la cadena de correo.

### Enviar el ticket

Después de completar todos los campos, seleccioná **Enviar** . El sistema confirma la creación del ticket y asigna un número de caso.

## Seguir y responder el ticket

Una vez creado el ticket, recibís un email con el enlace **View request** . Desde el portal de soporte podés ver el detalle del caso, leer las respuestas del equipo y agregar información.

### Responder desde el email

Cuando el equipo de soporte responde, recibís un email. Seleccioná **Responder**  para registrar tu respuesta automáticamente en el ticket.

**Regla:**  escribí la respuesta por encima de la línea `Reply above this line.`

### Responder desde el portal

1. Abrí el ticket desde **View request**  o desde el portal.

2. Leé la respuesta del agente en el hilo.

3. Agregá tu respuesta o información adicional.

4. Reabrí el ticket si fue marcado como resuelto, pero el problema continúa.

### Consultar las respuestas

Cuando el equipo de soporte responde, recibís una notificación. Podés seguir la conversación desde estos canales:

- **Email:**  recibís una notificación y podés responder directamente con el botón **Responder** .

- **Portal de soporte (Jira Service Management):**  la conversación completa queda disponible en el hilo del ticket. Accedé desde el enlace **View request**  del email o directamente desde el portal.

## Horario y días de atención

| Parámetro | Valor |
| --- | --- |
| Días | Lunes a viernes |
| Horario | 9:00 a 18:00 h |
| Zona horaria | GMT-3 (Argentina) |

Fuera del horario de atención:

El bot sigue disponible 24/7. Si el caso requiere atención personalizada, el equipo lo atiende el próximo día hábil y el SLA de primera respuesta personalizada se contabiliza únicamente dentro del horario de atención.
