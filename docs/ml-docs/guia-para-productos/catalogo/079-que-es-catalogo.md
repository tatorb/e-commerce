# Qué es catálogo

Nota:

Este recurso está disponible para Argentina, México, Brasil, Colombia, Chile, Uruguay, Perú y Ecuador

Los vendedores pueden crear publicaciones de catálogo con el contenido (títulos, fotos, descripciones y ficha técnica) provisto por Mercado Libre. Pueden realizarse publicaciones a partir de publicaciones actuales o creando una nueva publicación, y así competir con otros vendedores teniendo las mejores condiciones de venta para ganar la exposición en la Página de Producto (PdP). Estas páginas están posicionadas en los primeros lugares de los resultados de búsqueda.
